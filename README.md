# QR Code in Terminal (Offline)

A lightweight PHP command-line tool that generates QR codes directly in your terminal. 
It works **100% offline**, and can save QR codes as PNG or SVG, create WiFi QR codes, and process multiple links in batch.

---

## 🚀 Installation Guide

Since all the required files (including the `vendor` folder) are already included in this repository, you **do not** need to run `composer install`.

Clone this repository or download it as a ZIP:
